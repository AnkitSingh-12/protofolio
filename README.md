## ✨ Key Portfolio Features

### 1. 🎯 Dynamic Hero & Identity Module
* Multi-role typewriter headline (*AI / Generative AI Engineer*, *Agentic AI & LLM Specialist*, *Document Intelligence & Voice AI Developer*).
* Real-time status indicator: `Available for AI / Generative AI Engineer Roles`.
* 1-Click quick actions for Resume View, Direct Contact, and Recruiter Dashboard.

### 2. 👤 About Section Hero Card & Detailed Journey
* Custom display card layout featuring bold typography, marker highlight badge, hand-drawn vector accents, and an offset-bordered portrait photograph.
* Integrated quick links: LinkedIn, GitHub, Email, WhatsApp, and Phone.
* Full narrative story documenting personal vision, mission, and academic credentials from Chandigarh Engineering College.

### 3. 📂 Filterable Flagship & Experience Projects
Filter seamlessly across **All Projects (6)**, **Experience Projects (4)**, and **Independent Systems (2)**:
* **Autonomous AI Leads & Discovery Platform:** Multi-agent autonomous workflow engine powered by LangGraph, CrewAI, and ChromaDB.
* **Enterprise Retrieval-Augmented Generation (RAG) System:** Semantic document search and Q&A engine built on LangChain, FAISS, and localized LLMs.
* **MCP-Based Business Workflow Agents:** Model Context Protocol (MCP) agents automating enterprise operations and API integrations.
* **Low-Latency Real-Time AI Voice Agent:** Sub-800ms speech-to-speech conversational assistant over WebSockets with Whisper STT and FastSpeech TTS.
* **WorksBuddy Document AI & OCR Pipeline:** Production document digitization engine combining EasyOCR, PaddleOCR, and local Ollama inference.
* **Student Academic Performance & Retention Analytics:** Predictive classification pipeline for early identification of at-risk students.

### 4. 📊 Telemetry & Live Daily Visitor Tracking
* **Daily Profile Views:** Tracks total visits specifically for today with automatic 00:00 midnight rollover.
* **From LinkedIn:** Automatically detects inbound traffic from LinkedIn via `document.referrer` and tracking URLs (`?ref=linkedin`).
* **Active Viewers (Live):** Real-time concurrent online viewer counter with dynamic visual pulses.
* **Resume Download Counter:** Measures engagement and recruitment interest.

### 5. 📄 ATS Multi-Role Resume Generator
* Tailored resume generation for:
  * **AI / Generative AI Engineer**
  * **LLM, Agentic AI & RAG Specialist**
  * **Data Analyst & ML Specialist**
* Clean, 1-click printable PDF view optimized for Applicant Tracking Systems (ATS).

### 6. 🤖 In-Browser AI Assistant & Recruiter Copilot
* Local TF-IDF Job Description analyzer comparing candidate skills against any pasted recruiter job description.
* Interactive AI Assistant chatbot answering technical queries, architectural decisions, and experience highlights.
* Voice controller powered by the Web Speech API.

## 🚀 Getting Started (Local Development)

### Prerequisites
* **Node.js** (v18.17.0 or higher recommended)
* **npm** or **yarn** or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AnkitSingh-12/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **View in browser:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
